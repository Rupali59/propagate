# propagate — propagation

Safe to edit by hand.

**The layout of this directory is canonical in propagate's
`docs/REFERENCE.md` §"Propagation layout" — it is deliberately not restated
here.** A second description of the tree is one edit away from being the copy
that disagrees.

**This repo is public and carries only the tool.** Its working state (STATE,
DECISIONS, GOTCHAS, ISSUES, TODOS and their archive) and its working documents
(plans, audits, deferred designs) live in the private hub repo that surrounds
a maintainer's checkout, and each old path here holds a short *pointer stub*
saying so. A fresh clone therefore gets stubs rather than state; tests and
reports that read the moved files read the hub copy when it is present and skip
with a stated reason when it is not.

| Path | Holds |
|---|---|
| `state/workspace/`, `state/curate-docs/` | pointer stubs only — the files are in the private hub |
| `refs/` | branch + worktree registry, machine-local and gitignored: regenerated by `propagate migrate-refs <workspace> --apply` |
| `ledger.jsonl`, `ledger.md` | scaffolded empty by `init`; events live in the machine-local store |

`refs/lifecycle.jsonl` is append-only. Never edit past lines; supersede them.
